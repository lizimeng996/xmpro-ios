# XMPro iOS · 安装与使用说明

本项目是开源项目 [angusdevgo/XMPro](https://github.com/angusdevgo/XMPro) 的 iOS 原生移植版本，遵循 **AGPL-3.0-or-later** 许可协议（见 [LICENSE](../LICENSE)），供个人在自己的 Mac 上自行构建并安装到自有 iOS 设备使用。

---

## 1. 环境要求

| 项目 | 要求 |
| --- | --- |
| 电脑系统 | macOS（安装完整版 Xcode） |
| Xcode | Xcode 15+（推荐 Xcode 26 / 27 以启用原生 Liquid Glass 特性） |
| Swift 语言模式 | Swift 5（`SWIFT_VERSION = 5.0`） |
| iOS 部署版本 | iOS 16.0+（iOS 26.1+ 启用原生悬浮液态玻璃底栏与迷你播放条） |
| XcodeGen（可选） | 仅在修改 `project.yml` 需要重新生成 `.xcodeproj` 时使用 |

---

## 2. 构建与运行

### 方式一：直接打开随附工程（推荐）
1. 在项目根目录执行 `open XMPro.xcodeproj`（或双击打开）。
2. 在 Xcode 顶部选择目标设备（iOS 模拟器或已连接的 iPhone）。
3. 按 **`⌘B`** 编译、**`⌘R`** 运行、**`⌘U`** 运行全部单元测试。

### 方式二：使用 XcodeGen 重新生成工程
`project.yml` 是工程配置源。如需重新生成：

```bash
xcodegen generate
open XMPro.xcodeproj
```

> 重新生成会覆盖随附的 `XMPro.xcodeproj`，操作前建议先确认当前 Git 工作树干净。

## 3. 真机签名与侧载安装

默认配置如下（公开模板中 `DEVELOPMENT_TEAM` 保持为空，请勿将个人 Team ID 提交到公开仓库）：

| 配置项 | 默认值 |
| --- | --- |
| App Bundle ID | `studio.teikeng.xmpro` |
| 测试 Bundle ID | `studio.teikeng.xmpro.tests` |
| 签名方式 | Automatic |
| `DEVELOPMENT_TEAM` | 留空（本地自行选择） |

### 安装步骤
1. 使用数据线（或同一局域网配对）连接 iPhone 并在手机上点击「信任此电脑」。
2. 在 iPhone 的 **设置 → 隐私与安全性 → 开发者模式** 中开启开发者模式并按提示重启。
3. 在 Xcode 中点击左侧蓝色 **XMPro** 工程 → 选中 Target **XMPro** → **Signing & Capabilities** → 勾选 **Automatically manage signing**，在 **Team** 中选择自己的 Apple ID。
   - 若提示 Bundle Identifier 已被占用，将 `studio.teikeng.xmpro` 修改为你自己的唯一标识（例如 `com.yourname.xmpro`）。
4. 顶部设备栏选择你的 iPhone，按 **`⌘R`** 编译安装。
5. 首次在手机桌面打开若提示「未受信任的开发者」，前往 iPhone **设置 → 通用 → VPN与设备管理** 信任对应开发者账号即可。

> **自签有效期说明**：使用个人免费 Apple ID 签名安装的 App 有效期通常为 7 天，到期后重新连接 Xcode 按 `⌘R` 覆盖安装即可，本地书签、设置与 Keychain 中的登录凭据不会丢失。

## 4. 功能使用指引

### 登录账号
- 进入底部 **「我的」→「账号与听时」**，支持两种方式：
  - **短信登录**：输入手机号 → 完成安全滑块验证 → 输入短信验证码登录。
  - **导入 Cookie / JSON**：粘贴极速版 Cookie 字符串或导出的登录 JSON 即可快速导入。

### 听书与播放
- **主页**：顶部搜索专辑或声音、横向切换频道（小说频道支持自动识别二级分类与排行榜）、点击专辑进入选集页。
- **选集区间**：在专辑页点击 **「选集区间」**，可按 100 集网格快速跳转，也可手动输入「起始集 至 结束集」或点击「显示全部」。
- **全屏播放器**：点击底部悬浮迷你播放条进入全屏播放器，可调节倍速、音效（人声增强 / 重低音 / 3D 环绕 / 音量均衡）、音质、定时关闭、跳过头尾、查看评论与同步字幕 / 文稿、打开待播列表并一键置顶 / 定位 / 置底。
- **系统实时字幕技巧**：喜马拉雅极速版未公开普通有声书的 AI 逐字字幕接口；如需对所有有声书生成实时中文悬浮字幕，可直接在 iPhone **设置 → 辅助功能 → 实时字幕** 中开启 Apple 系统端侧离线实时转写。

### 福利与听时
- 在 **「我的」** 顶部卡片可直接点击 **「查询时长」**、**「单次领取」** 或切换 **「自动领取·开/关」**。
- 进入 **「账号与听时」→「听时账本与福利任务详情」** 可查看累计播放时长、待上报记录与福利任务列表。

### 备份与恢复（Android / iOS 互通）
- 进入 **「我的」→「备份与恢复」**：
  - 支持通过系统「文件」App 导出或导入 JSON 备份，兼容 Android 版 XMPro 备份格式；
  - 默认不包含敏感登录信息；如勾选「导出时包含账号登录信息」，生成的明文 JSON 请妥善保管，切勿上传到公开位置。

## 5. 数据与隐私说明

- **本地状态文件**：保存在 App 沙盒 `Application Support/XMPro/state.json`，采用临时文件原子替换写入，并严格校验禁止将 Token / Cookie / 设备标识写入普通状态 JSON。
- **凭据存储**：账号 Token 与安装级 `deviceId` 单独存储在 iOS **Keychain**（Service: `studio.teikeng.xmpro.credentials`）。
- **无第三方追踪**：应用仅与目标音频服务通信，不包含任何广告或第三方统计 SDK。
