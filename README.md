# XMPro iOS

基于原生 **Swift / SwiftUI / AVFoundation** 打造的第三方喜马拉雅极速版 iOS 收听客户端，采用 **iOS 26 / iOS 27 Liquid Glass（液态玻璃）** 设计语言，供个人学习与自有设备自签侧载使用。

## 功能特性

### 1. 发现与内容浏览
- **多频道与榜单**：支持推荐、小说、相声评书、儿童、历史、听音乐等频道切换与二级子分类自动加载，提供自动轮播图、排行榜（TOP 榜）与大横卡推荐流。
- **双模式搜索**：支持按专辑或声音关键词检索、热门搜索词快捷触发及分页加载。
- **专辑选集与区间筛选**：支持跨分段选集（100 集网格区间与自定义「起始集–结束集」精确范围查看）、正序 / 倒序切换、列表一键置顶 / 定位当前 / 置底。
- **主播主页**：查看主播资料、关注 / 粉丝 / 专辑数及作品列表，点击作品直达专辑页。

### 2. 听书书架与云端同步
- **五合一书架**：在一个页面内通过液态玻璃胶囊自由切换 **听更新 / 订阅 / 历史 / 收藏 / 书签**，并支持顶部关键词实时过滤。
- **跨设备历史续播**：支持云端收听历史拉取、本地与云端续播位置策略及播放进度自动写回。
- **本地书签**：播放中一键打点保存书签，随时定位回放。

### 3. 沉浸式播放器与音频引擎
- **iOS 26 / iOS 27 原生液态玻璃交互**：底部采用原生悬浮 `TabView`（向下滚动自动收缩）与 Apple Music 同款 `.tabViewBottomAccessory` 悬浮迷你播放条，点击拉起全屏「正在收听」播放器。
- **实时音频 DSP 音效引擎**：基于 `AVFoundation` / `MTAudioProcessingTap` 与 Biquad 滤波器实现 5 档音效（关闭 / 人声增强 / 重低音 / 3D 环绕 / 音量均衡）。
- **完备的收听控制**：
  - `0.5×` – `3.0×` 倍速调节与持久化；
  - 快退 10 秒 / 快进 30 秒、上一集 / 下一集、进度条拖动、软件音量调节；
  - 定时关闭（15 / 30 / 45 / 60 / 90 分钟）；
  - 跳过头尾（支持自定义单集开头与结尾裁剪比例，可在播放页一键开关或长按调节）；
  - 后台持续播放、锁屏媒体信息展示与耳机 / 车机远程控制。
- **互动与文稿**：
  - 播放页实时展示**评论数角标**与分层评论抽屉；
  - 支持读取曲目 LRC 同步字幕（高亮滚动与点击跳转）及富文本章节文稿；
  - 底部**待播列表**抽屉，支持清空与顶部 / 当前集 / 底部一键定位。

### 4. 多账号、听时管理与隐私安全
- **多种登录方式**：支持手机号 + GeeTest 安全验证短信登录，以及 Cookie / 导出 JSON 凭据导入。
- **多账号隔离与凭据安全**：认证凭据加密保存在系统 **Keychain**，不写入普通状态文件；支持多账号切换、设为主账号、自定义显示名、同步资料与一键退出。
- **听时额度与福利**：支持设备听时查询、单次福利领取、低水位自动领取开关与按账号隔离的听时账本。
- **双向备份互通**：通过系统「文件」App 导入 / 导出 JSON 备份，兼容 Android 版 XMPro 的状态格式，支持按需选择是否包含登录信息。

### 5. 外观与可访问性
- 内置 5 套主题：**跟随系统 / 绯红浅色 / 绯红深色 / 暖纸护眼 / 午夜高对比**，全面支持浅色与深色模式及系统动态字体。
- 可在设置中自由编辑首页频道顺序与显示开关。

## 构建与安装

本项目**不以上架 App Store 为目标**，在 [Releases](https://github.com/lizimeng996/xmpro-ios/releases) 提供**无签名 IPA** 供个人自有设备自签侧载使用，也支持在 Mac 上使用 Xcode 从源码自行编译。

### 环境要求
- **直接使用无签名 IPA**：iOS **17.0+** 真机（由 Xcode 27.2 编译构建），配合自签侧载工具（无需 Mac）；
- **从源码自行编译**：macOS 与 **Xcode 15+**（推荐 Xcode 26 / 27 以体验完整原生 Liquid Glass 特性）、Swift 5.9+ 编译器，支持 iOS **16.0+** 真机或模拟器（iOS 26.1+ 自动启用原生 Liquid Glass 底栏与悬浮迷你播放条，低版本自动平滑回退为毛玻璃视觉）。

### 快速开始

#### 方式一：下载无签名 IPA 自签安装（无需 Mac）
1. 前往 [Releases](https://github.com/lizimeng996/xmpro-ios/releases) 下载最新的 `XMPro-*-unsigned.ipa`（已去除全部个人签名与本机路径信息）。
2. 使用 **Sideloadly / AltStore / SideStore / 爱思助手 / 轻松签 / TrollStore** 等工具，选择你自己的 Apple ID 或证书签名安装到自有设备：
   - 若工具提示默认 Bundle ID（`studio.teikeng.xmpro`）已被占用，在签名工具中改为你自己的唯一标识即可；
   - 使用免费个人 Apple ID 自签的有效期通常为 7 天，到期前覆盖重签即可保留本地数据与登录状态。

#### 方式二：从源码自行编译（macOS + Xcode）
1. 克隆仓库并打开工程：
   ```bash
   git clone https://github.com/lizimeng996/xmpro-ios.git
   cd xmpro-ios
   open XMPro.xcodeproj
   ```
2. 在 Xcode 左侧选择 **XMPro** 项目 → **Signing & Capabilities** → 勾选 **Automatically manage signing**，选择你自己的 Apple ID Team（若默认 Bundle ID 冲突，请修改为自定义标识）。
3. 顶部选择你的 iPhone 真机或模拟器，按 **`⌘R`** 编译运行；按 **`⌘U`** 运行单元测试。

详细的安装、签名维护、XcodeGen 重新生成与备份互通说明，请阅读：
- [使用说明（安装与功能指引）](docs/使用说明.md)
- [构建指南（BUILD.md）](BUILD.md)
